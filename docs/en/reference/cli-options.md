# CLI options and defaults

Generated by `scripts/dev/sync_docs.py` from the Click registry. For what each command is for, its side effects and when to use it, see the [CLI reference](cli.md) and the [side-effect inventory](cli-surface.md). `cne <command> --help` prints the same options in Chinese.

## `cne audit`

| Option | Default | Description |
|---|---|---|
| `--config` | `configs/cnequity.toml` | Path to the config file. |
| `--run-id` | `—` | Run ID; repeat to merge evidence from these runs into one audit. |
| `--full` | `False` | Health snapshot of the whole lake (current state + freshness), not the files of a single run. |
| `--research-start` | `—` | Strictly validate the research window starting on this date (requires --full). |
| `--quality-only` | `False` | With --full: gate only on quality errors; check schedule freshness separately with status. |
| `--research-end` | `—` | End of the research window (defaults to the latest daily_bars; requires --research-start). |
| `--research-universe` | `all_a` | Historical research universe checked by --full. |

## `cne backfill`

| Option | Default | Description |
|---|---|---|
| `dataset` | `—` | Required; positional argument |
| `--config` | `configs/cnequity.toml` | Path to the config file. |
| `--profile` | `default` | daily_bars accepts delisted: backfill only the confirmed delisting list, reusing the independent discovery evidence. |
| `--shfe-annual-archive` | `—` | Futures/options daily bars only: import offline from a local SHFE annual ZIP in a verified format. |
| `--archive-year` | `—` | Trading year covered by the annual ZIP. |
| `--accept-partial-fields` | `False` | Explicitly accept that the annual package lacks fields found only in the daily files; existing complete daily bars are not overwritten. |
| `--archive-url` | `—` | Optional: the original HTTPS URL of this ZIP on the SHFE website; written to evidence only. |
| `--archive-downloaded-at` | `—` | Optional: known original download time, ISO 8601 with time zone. |
| `--plan` | `False` | Print only sources, scope and fetch method, plus a request budget for derivatives. Fetches no data and does not write the lake. |
| `--exchange` | `—` | Derivatives only: restrict to an exchange; repeatable. INE is routed via SHF; 2018 futures also fetch INE daily files. |
| `--refresh` | `False` | Derivatives daily bars only: ignore completion receipts and the response cache and re-check the given range; does not bypass circuit breakers. |
| `--retry-failed` | `False` | Resume the sector_bars backfill (skip sectors already written in the checkpoint). |
| `--force` | `False` | Clear the sector_bars backfill checkpoint and refetch all sectors. |
| `--start` | `—` | Backfill start date (YYYY-MM-DD), covering daily_bars, minute_bars, derivatives daily bars, date/report-period advancement and sector_bars. sector_bars defaults to 400 days back; ranges beyond the source's history depth are kept as gaps, while the available range is delivered as usual with guidance for filling the rest. |
| `--end` | `—` | Backfill end date (YYYY-MM-DD, default today); with --start, bounds the historical window. |
| `--outstanding` | `False` | Repair only the keys owed by tolerated gaps; scope and window come from the debt ledger, ignoring --symbols/--start/--end. Filled keys are cleared from the ledger; keys still missing stay owed. |
| `--max-attempts` | `10` | With --outstanding only: after a key has missed this many attempts it is parked. Later --outstanding runs skip it by default, but it stays in the ledger. |
| `--retry-parked` | `False` | With --outstanding only: ignore the attempt cap and include parked keys in this repair. |
| `--symbols` | `—` | Comma-separated symbols to restrict the scope: for scoped backfills of intraday, trading_status and corporate_actions, and scoped repairs of financial_statement_items, daily_bars and share_structure. trading_status records the exact scope in its checkpoint and coverage evidence; daily_bars writes this explicit scope into the backfill metadata. |
| `--workers` | `1` | margin_trading only: concurrency for date advancement. Each request still goes through the shared source rate limiter from the config; must be 1 for other datasets. |
| `--margin-source` | `—` | margin_trading only: source to use for this backfill, without changing the config file or source rate limits. |
| `--payment-date-repair` | `False` | corporate_actions only: apply reviewed issuer announcements first, then match actual payment dates with Baostock; payment dates earlier than the ex-date are treated as unknown. |
| `--issuer-notice-repair` | `False` | corporate_actions only: repair payment dates and reviewed bonus/transfer share terms using issuer implementation announcements only (reviewed list, CNINFO, BSE); unmatched events stay as gaps and Baostock is not queried. |
| `--baostock-repair` | `False` | corporate_actions only: explicitly repair delisted Shanghai and Shenzhen symbols with Baostock. |
| `--ths-repair` | `False` | corporate_actions only, for historical migration: fill historical dividends and ex-rights of delisted BSE symbols from THS. |
| `--eastmoney-bj-repair` | `False` | corporate_actions only, for historical migration: fill historical dividends and ex-rights of old BSE codes via the current 920xxx EastMoney codes. |
| `--eastmoney-date-repair` | `False` | corporate_actions only: request historical ex-rights rows from EastMoney day by day for the ex-dates given in --ex-dates. The primary source for the backfill path is TDX; only EastMoney's daily-update equality filter can reach rows before 2015-09-29. |
| `--ex-dates` | `—` | With --eastmoney-date-repair: comma-separated ex-dates, YYYY-MM-DD. |
| `--bse-tip-repair` | `False` | daily_bars only, for historical migration: fill BJ turnover for existing current-period trading days from the BSE website without refetching Sina. Daily updates already use the BSE quote board as the primary current-period source for BJ. |
| `--bj-amount-repair` | `False` | daily_bars only, superseded by --tdx-amount-repair: fill BSE turnover that Sina never published from TDX; stored prices and volumes are never touched. Requires --start/--end. |
| `--tdx-amount-repair` | `False` | daily_bars only: cross-check historical Shanghai, Shenzhen and Beijing rows filled from Sina against TDX, filling turnover only when OHLC match and the volume difference is under one lot; codes TDX lacks keep the Sina rows. Stored prices and volumes are never touched. Requires --start/--end. |
| `--qmt-amount-repair` | `False` | daily_bars only: fill the turnover of Sina rows for delisted BSE names from the BigQMT bridge; fills only when open/high/low/close agree and the volume difference is under one lot; stored prices and volumes are never touched. Requires --symbols and --start/--end. |
| `--qmt-bars-repair` | `False` | daily_bars only: fill missing BSE daily bars from the BigQMT bridge; writes only keys missing from the curated lake; rows outside the listing window or with zero volume do not count as coverage. Requires --symbols and --start/--end. |
| `--tdx-volume-repair` | `False` | daily_bars only: re-read TDX and rewrite only the volume of stored TDX rows (fixes the decoding bug before 2026-09-17); prices must match, and turnover values under 64.5 yuan, which the same bug inflated, are rewritten too; adds no rows. Requires --symbols and --start/--end. |
| `--turnover-repair` | `False` | daily_bars only: replace Shanghai/Shenzhen stock rows whose turnover is missing, zero or has misaligned volume/amount units with the whole same-day Baostock row; OHLC must agree within half a cent, otherwise or if unavailable the original values are kept. Requires --start/--end. |
| `--turnover-peer-review` | `False` | With --turnover-repair: review price conflicts using historical exchange prices, TDX and EastMoney; replace whole bars only with agreeing evidence, never splice exchange-wide turnover. |
| `--fill-em-outage` | `False` | valuation_metrics only: when the EastMoney snapshot is interrupted, fill the --start/--end window after EastMoney's last complete day and before today from the EastMoney datacenter valuation report; writes only when the whole market is retrieved. |

## `cne init`

| Option | Default | Description |
|---|---|---|
| `--config` | `configs/cnequity.toml` | Path to the config file. |
| `--profile` | `quick` | How big to build. demo = fetch a few symbols from real sources; sample = the same shape but offline and deterministic — neither is a market. quick = all symbols, last 3 years; full = all symbols since 2016-01-01 (usually needs more pages). You can deepen history later with `cne backfill daily_bars`. |
| `--symbols` | `600519.SH,000001.SZ,000858.SZ,300750.SZ,601318.SH` | demo/sample: symbols to fetch, comma-separated (deliberately few). |
| `--days` | `30` | demo/sample: roughly how many recent trading days of daily_bars to fetch. |
| `--data-root` | `data/cnequity-demo` | demo/sample: separate lake root (do not use it for a full-market init). |
| `--config-out` | `configs/cnequity.demo.toml` | demo/sample: where to write the small config for later `cne query` use. |
| `--force` | `False` | demo/sample: allow overwriting an existing --config-out with different content; by default refuses and keeps the original file. |
| `--intraday` | `False` | demo/sample: also fetch 1-minute bars for the same symbols (up to 5 trading days) and print one trading day, so the bar_time convention is visible. |
| `--research` | `False` | demo/sample: also derive hfq adjustment factors from Sina and print an unadjusted vs. adjusted return comparison (slower; needs access to Sina). |
| `--layout-only` | `False` | Create only directories, the manifest and DuckDB views; skip the init stages. |
| `--trade-date` | `—` | As-of trading day (YYYY-MM-DD) for the init stages; defaults to today. |
| `--resume` | `False` | Resume the most recent unfinished init run (retry failed batches + fill missing stages). |
| `--run-id` | `—` | Resume the given init run_id (implies --resume). |
| `--keep-going` | `False` | Keep going after a stage fails instead of stopping. |
| `--since` | `—` | Explicit history start (YYYY-MM-DD); overrides --profile. |
| `--quiet` | `False` | Show only warnings and above; no per-batch progress. |
| `--pack` | `—` | Research pack: market (market data), fundamentals, universe (historical ST). Does not change what this init downloads. Decides which schedule groups stay updated afterward and the verdict of `cne check --pack`. Repeatable. If omitted, the saved selection is reused; the first time it is market. |
| `--schedule` | `False` | After init succeeds, install the scheduled daily update and closing catch-up for the selected research packs. Excludes announcements and news. |
| `--json` | `False` | Print the full machine-readable result at the end instead of the summary; the full result is always saved to the log directory too. |
| `--no-preflight` | `False` | Skip the network preflight (TDX, exchanges, EastMoney) of up to 8 seconds before the run starts. Setting CNE_SKIP_PREFLIGHT=1 does the same. |
